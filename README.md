⚡ Load Smart Grid – Electricity Load Scheduling

About the Project

Load Smart Grid is an electricity load scheduling system that helps reduce peak electricity demand.

The system schedules flexible electrical loads to suitable time slots instead of running them all during peak hours. 
This helps distribute electricity usage more efficiently and reduces the overall peak load.

The project uses a Greedy Algorithm to make scheduling decisions based on available time slots and electricity demand.

The main aim of this project is to reduce peak demand, improve energy utilization, and create an efficient electricity scheduling system.
